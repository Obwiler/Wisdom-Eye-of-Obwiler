## 一、发展方向总览

```
v0.2.0 ────► v0.3.0 ────► v1.0.0 ────► v1.x+
 (当前)      (实机验证)    (架构重构)    (生态扩展)
```

### Phase A: 实机验证与打磨 (v0.3.0) — 1-2 周

目标: 在 RG_Glasses 真机上完成全流程验证，修复实测问题。

1. **完整实机测试**
   - 拍照→AI分析→结果展示 全流程
   - 不同光照/角度/距离下的识别效果
   - 按键操作的响应延迟
   - 网络断开/超时场景的 UI 反馈

2. **性能调优**
   - ImagePipeline 处理耗时（目标 < 500ms）
   - HttpAiClient 首字节延迟
   - APK 冷启动时间
   - 内存占用（拍照+处理峰值）

3. **微交互打磨**
   - 拍照成功/失败的状态反馈动画
   - AI 分析中的 loading 指示
   - 按键震动反馈（如硬件支持）
   - 错误提示的文案优化

4. **硬件适配确认**
   - RG_Glasses 的 480×640 单色屏显示效果
   - 镜腿触摸条按键映射
   - 电池续航（保活服务影响）
   - 散热表现

### Phase B: 架构升级 (v1.0.0) — 2-4 周

目标: PC 工具架构重构，对标"眼镜管家"定位。

1. **PC 工具 v1.0 重构** (参照 WEO_PC_ARCH_V1.0.md)
   - NavRail 左侧图标导航（7-8 个面板入口）
   - 仪表盘 (Dashboard): 设备概览 + WEO 状态 + 快捷操作
   - 应用商店 (AppStore): 手表应用浏览+安装
   - 文件管理器增强: 树形浏览 + 拖拽上传
   - Shell 终端: 快捷命令 + 历史记录
   - 主题引擎: JSON 驱动 + 热切换

2. **ADB 连接增强**
   - 无线 ADB 自动重连
   - 多设备列表（预留，当前单设备）
   - 连接状态实时监控

3. **APK 端增强**
   - 连续拍照模式（拍多张，选最佳）
   - 语音播报结果（TTS）
   - 离线模式（本地 OCR 兜底）
   - 设置页改为可编辑（直接修改配置）

### Phase C: 生态扩展 (v1.x+) — 按需推进

1. **多 AI 模型支持**
   - 模型切换热键（不同场景用不同模型）
   - 结果对比模式（同时调用两个模型）
   - 自定义 Prompt 模板管理

2. **数据与分析**
   - 拍照历史记录与回看
   - 识别准确率统计
   - 使用频率热力图

3. **分享与协作**
   - 蓝牙/WiFi Direct 传输图片到手机
   - 生成分享卡片（含原图+AI结果）
   - 微信/Telegram Bot 集成

4. **开发者工具**
   - APK 日志实时查看（logcat 面板）
   - 性能监控仪表盘（CPU/内存/网络）
   - 一键性能报告生成
