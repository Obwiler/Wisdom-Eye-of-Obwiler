## 二、FIX-1 — 创建统一后台轮询 Worker
## ═══════════════════════════════════════

### 2.1 背景

审计 A1：当前 `_on_timer()` 每 5 秒在主线程执行 3 次 `subprocess.run()`，是卡顿根源。

### 2.2 方案

创建 `ui/poll_worker.py`——单一 QThread，每轮执行全部 ADB 查询，通过一个 `result` 信号回传字典，主线程仅更新 UI。

### 2.3 接口设计

```python
class PollWorker(QThread):
    result = Signal(dict)
    # dict = {
    #     "serial": str|None,
    #     "model": str,
    #     "android": str,
    #     "installed": bool,
    # }

    def __init__(self, adb: AdbBridge, pkg: str, parent=None):
        ...

    def run(self):
        # 1. first_online()
        # 2. get_device_info()
        # 3. is_installed(pkg)
        # result.emit({...})
```

### 2.4 轮询策略

| 参数 | 旧值 | 新值 |
|------|------|------|
| 轮询间隔 | 5000ms | **15000ms** |
| 启动首次扫描 | 构造时同步 | **窗口 show 后 500ms 触发首轮** |
| 超时 | 各命令独立 15s | 整个 run() 统一 30s |

### 3.2 _PollWorker 集成

```python
def _on_timer(self):
    if self._poll_worker and self._poll_worker.isRunning():
        return
    self._poll_worker = PollWorker(self._adb, self._cfg.pkg_name, self)
    self._poll_worker.result.connect(self._on_poll_result)
    self._poll_worker.finished.connect(self._poll_worker.deleteLater)
    self._poll_worker.start()

def _on_poll_result(self, data: dict):
    serial = data.get("serial")
    if serial:
        self._adb.serial = serial
    self._status.set_info(
        serial=serial,
        model=data.get("model", ""),
        android=data.get("android", ""),
    )
    self._apk_panel.set_installed(data.get("installed", False))
```

## 六、FIX-5 — 重构 config_panel.py 推拉后台化
## ═══════════════════════════════════════

### 6.1 问题

审计：`_on_push()` 3 次 `subprocess.run()` + `_on_pull()` 1 次，全在主线程。

### 6.2 方案

创建 `_PushPullThread`，推/拉操作通过 QThread 执行，信号驱动 UI 恢复。

### 6.3 变更

```python
class _PushPullThread(QThread):
    finished = Signal(bool, str, dict|None)
    # push: finished(True, "推送成功", None)
    # pull: finished(True, "已拉取", config_dict)

    def __init__(self, sync: ConfigSync, action: str, config_dict=None, parent=None):
        self._sync = sync
        self._action = action  # "push" | "pull"
        self._cfg = config_dict

    def run(self):
        if self._action == "push":
            ok = self._sync.push(self._cfg)
            self.finished.emit(ok, "推送" + ("成功" if ok else "失败"), None)
        else:
            cfg = self._sync.pull()
            if cfg:
                self.finished.emit(True, "已拉取", cfg)
            else:
                self.finished.emit(False, "设备上无配置文件", None)
```

`_on_push` / `_on_pull` 创建 `_PushPullThread`，`finished` 信号驱动 UI 更新，按钮操作期间 disable。

## 十三、风险与回滚
## ═══════════════════════════════════════

| 风险 | 缓解 |
|------|------|
| uvicorn/Qt 事件循环冲突 | 仅用 QThread，不引入任何新框架 |
| PollWorker ADB 命令串行化后首次启动慢 | 首轮 result 触发后才启动 QTimer 间隔，不依赖首轮速度 |
| QThread 对象生命周期管理 | 统一 `deleteLater` + `isRunning()` 守卫模式 |
| UI 意外变更 | 严格限定修改范围：仅动信号连接/槽函数/数据注入，不动任何 widget 构造代码 |
